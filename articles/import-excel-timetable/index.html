Import Your Excel Timetable into TermPoint

You already did the work of building a schedule. You shouldn't have to retype it.

Most department schedulers who try TermPoint have a timetable that already lives in a spreadsheet, perhaps last year's, perhaps a semester in progress. Entering a few hundred sections by hand is exactly the kind of chore that keeps people from switching tools. So TermPoint can import them for you, from an Excel workbook (.xlsx) or a CSV file.

The import is deliberately strict and deliberately cautious. Nothing is added until the whole file has passed every check, and you see exactly what will happen before you confirm it.

Step 1: Get the template and fill it in

From the import window in TermPoint you can save a sample workbook and read written instructions, either on screen or saved as a web page. The instructions are also built into the workbook itself, so a colleague preparing the data elsewhere needs nothing else. The details of the format live there, in the app, so we won't repeat them here.

In outline, the template is a single sheet with a row for each meeting of a section, and columns for the things a scheduler actually tracks: subject, course, section, instructors, times, rooms and so on. Only the columns that identify a section are required.

This is the part only you can do, because every department's spreadsheet is laid out differently. Copy your data into the template's columns, using standard spreadsheet tools to shape your data.

Step 2: Check, then confirm

Choose your file in the import window. TermPoint reads the entire file and checks it without changing anything. There are three possible outcomes.

There are problems. You get a plain-language list, each item naming the row and column it came from. Nothing has been imported. Fix the file, choose it again, and repeat.

It's ready. You see a summary of what will be added: how many sections, new courses and new instructors, plus any rooms, tags or other setup values that TermPoint doesn't have yet. Warnings are shown too, but they don't block the import. They are there so you can decide whether you meant it. Then you confirm.

There's nothing to add. Every section in the file is already in the semester.

Guarding against typos

Because the file can introduce new instructors, tags, section types and rooms, a typo could quietly create a stray record: "Lectrue" instead of "Lecture". TermPoint defends against that in two ways. It lists everything that will be newly created before you confirm anything, and it points out new names that look like a misspelling of one it already has.

Records created by the import start out with only the details the file gave them, so a new room, for instance, has no capacity or room type until you fill those in.

Importing again is safe

Realistically, you'll forget something. A section already in the semester is skipped and never changed, so you can fix your file and import it again, and only the sections that are new are added. Edits you've made in TermPoint since the first import are safe.

The same property lets you split a semester into one file per subject and import them one after another.

What the import doesn't do

  • It adds sections. It never updates existing sections, courses, instructors or setup values.
  • It fills one semester at a time.
  • It has no undo. A wrong import is backed out by emptying the semester, which removes every section in it, so it's worth checking the preview carefully before you confirm.
  • It is part of the desktop application. The online demo is for looking around, not importing.

Your spreadsheet stays on your own machine throughout. TermPoint reads the file locally and sends it nowhere.

Why bother

A spreadsheet is a fine place to start a timetable and a poor place to keep one, as we discuss in The Scheduler the System Forgot. Importing means switching tools costs an afternoon of tidying a file, not weeks of re-entry, and you keep the original spreadsheet untouched as a fallback.
